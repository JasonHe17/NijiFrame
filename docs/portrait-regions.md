# 人像区域建议（实验）

在“局部”中选择“建议人像区域（实验）”，查看红色覆盖区域，再选择“采用并修正”或“保留原区域”。采用会替换当前区域与笔画，但保留曝光、柔肤等强度；可立即撤销，也可继续添加／擦除。只有应用工具调整后才自动保存。识别不会自动开启柔肤。取消分析会丢弃结果，但需要等待正在执行的本地推理结束。

这是单人照片的几何区域起点，不是精确皮肤分割。脸部轮廓内大致排除眼睛、眉毛、嘴唇，仍可能覆盖眼镜、胡须、头发、手或其他遮挡。请检查区域，必要时擦除；使用原尺寸细节查看判断实际效果。侧脸、小人脸、低光、遮挡可能失败。检测到多张脸时拒绝建议；没有检测到第二张脸也不能证明照片只有一人。失败不会覆盖已有区域，可继续手工操作。

## 实现与边界

- Android 运行 MediaPipe Tasks Vision/Core **1.1.0**，固定 Face Landmarker float16 `/1/` 模型。CPU、单张图像模式、最多检测两张脸，检测／存在阈值均为 0.5；不输出表情系数、身份或人脸变形。
- 按用户请求分析 EXIF 归一化的原图代理，长边不超过 1024，不使用已调整的预览或裁剪后图像。工作与像素渲染串行，创建模型前检查至少 80 MiB 可用预算；该预算不是峰值保证。每次分析后关闭模型与输入图像，不在每次调参时重新运行。
- 使用运行库提供的轮廓连接定义生成凸包。在图像像素坐标中排除眼、眉、唇凸包，保护边界扩展 `max(2, faceWidth*0.015)` 像素，以到边界的距离线性羽化 `max(2, faceWidth*0.025)` 像素。没有肤色分类、统计肤色查表、生成式网络或自动质量评分。
- 建议保存为长边不超过 256 的 8 位覆盖网格；手工笔画随后在现有长边 1024 覆盖网格上组合。它适合粗选，不能提供像素级轮廓。原图、建议和笔画均保持源坐标；裁剪／旋转不会改变对应内容。
- 整图没有输出关键点时，在中心、左上、右上、左下、右下各检查一次半宽／半高窗口；最多额外 5 次推理，仍使用相同的 0.5 阈值。窗口结果先映射回完整源坐标，再以关键点包围框 IoU≥0.5 合并同位置候选；不同位置或单窗口出现多个候选时拒绝自动区域，不取第一个结果。候选严重越过窗口边界时丢弃；所有窗口完成后才接受唯一位置。
- 整图已输出一个候选时沿用原路径，不额外搜索；因此这仍不是“照片只有一个人”的证明。分区结果也可能误检，始终先检查建议再采用。分区只影响分析输入，不裁切照片、不变更编辑构图。
- 工程 v5 保存已接受的覆盖值与笔画。重开、跨设备读取和导出依赖这些数值，不依赖模型重跑；后续升级模型不会重新解释旧工程。v1–v4 可读取并按原语义迁移；旧版应用不能打开 v5，应先备份工程。

## 模型与离线处理

模型在构建时从固定官方地址下载并验证 SHA-256，随 APK 打包；应用不下载模型、不上传照片。清单明确移除运行库带入的 INTERNET、网络状态及唤醒权限，以及指标上传后台服务／接收器。运行库含指标代码；上游隐私声明仍保留在 APK，当前应用没有其网络传输能力，也不注册传输后台组件。将来增加网络功能必须重新核验这个边界。
