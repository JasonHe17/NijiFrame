# 编辑体验与人像工作流阶段

阶段分支：`dev/editor-experience`，基于已经验证的稳定性候选 `68e73e0`；该基线尚未合入main。本阶段不按小改动分别创建PR，完成后集中验收。

## 目标与范围

1. 紧凑的编辑布局：单一保存状态入口，照片技术信息按需查看；未选工具时收起空白工具空间，短屏和大字体仍可操作。
2. 局部交互：全图与原尺寸窗口共享添加／擦除、覆盖显示、笔刷大小与硬度控制；清楚区分移动／查看与绘制，以及对比原图时的只读状态。
3. 人像流程：局部工具按“选区与修正→调整效果→原尺寸对比”组织，保留已有自动建议、手工回退、应用／取消和撤销语义。采用建议不自动开启柔肤。

4. 现代化编辑器：中性双主题、独立画布偏好、四类工具、相对刻度与精确输入、所有工具的草稿撤销，以及明确完成／取消。详细交互契约与研究来源见 [modern-editor.md](modern-editor.md)。

本阶段继续完成上述范围，局部颜色另设阶段；不引入新算法、模型、工程版本、RAW/HDR、Windows客户端或通用框架。

## 布局原型与操作约定

- 顶部：项目入口、工程名称与保存状态、导出、更多菜单。
- 画布下方：撤销／重做、原图对比、细节与适应画布；操作结果有独立提示，保存状态不被“已导出”替代。
- 中部：照片画布；照片编码与颜色信息移入“工程与照片信息”。
- 底部或宽屏侧栏：工具导航；选定工具后展示操作区，应用／取消固定在操作区之外。
- 局部工具：“选区与修正”提供建议／手工区域及笔刷；“调整效果”隐藏覆盖并停止绘制，提供局部曝光、柔肤和细节保护。回到选区时恢复覆盖及上次绘制模式。
- 导出设置本身不应用草稿；点击保存／分享时才应用，并明确说明。取消系统位置选择仍保留已经应用的工程修改。

## 验收任务

- 快速调整照片：找到工具、修改、取消／应用、原图对比；能区分草稿与已保存工程。
- 修正人像区域：建议失败时能继续手工绘制；添加／擦除／笔刷属性在两种视图一致；对比原图不写入笔画；效果检查不被红色覆盖遮挡。
- 保存后继续：重开、导出设置取消不应用草稿、确认输出后保存、工程往返及升级保持原图和参数。
- 检查竖屏、横屏、短屏与大字体；测量合成样例下画布空间，并检查可达控件和真实触摸结果。自动化操作成功不等于真实用户或人像画质验收。

## 来源与调查边界

保留Compose Material组件的触摸与无障碍语义，参考[Android触摸目标说明](https://developer.android.com/develop/ui/compose/accessibility/api-defaults)。不缩小触摸目标换取画布面积，不新增依赖或借用竞品图标／截图。

现有[人像专利线索](portrait-region-patents.md)仍适用；本次仅重新组织既有区域与效果，不改变关键点、滤波与融合实现。笔刷仍修改显式蒙版，不加入预载多效果笔刷、自动吸附或双圆光标。本阶段原型与专利补查记录随实现更新；GUI授权图样与完整法律状态未清障。

## 笔刷交互复查

本轮重读[US8687015B2权1/9/14/20/23](https://patents.google.com/patent/US8687015B2/en)：其组合包括先对整图应用调整、响应局部笔刷输入检测边缘并恢复其余区域。本工具始终保留独立的显式区域与效果参数，不增加该整图预应用／边缘检测流程。选区和效果分步只是操作组织，不能单独作为专利绕行依据；人像关键点相关重合仍见既有记录。GUI检索命中包括USD780792S1，但本轮未取得可逐图核验的授权图样，因此外观设计与官方状态仍待核查，不记作清障通过。
