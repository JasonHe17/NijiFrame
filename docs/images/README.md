# README images

## Application screenshots

`editor-light.jpg` and `editor-crop.jpg` show the actual NijiFrame Android UI from source commit `8037d07b5079d06b4d7c724b22d2123954942d1a` (0.2.0-dev), captured on 2026-10-15 in an API 36 emulator. The first shows the light panel at neutral exposure; the second shows an unapplied 1:1 crop. These illustrate controls, not a portrait-retouching before/after result. Only the system status/navigation bars were cropped, then the images were resized and JPEG-compressed; app controls and photo pixels were not composited or replaced.
