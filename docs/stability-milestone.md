# 大图工程与编辑稳定性阶段

状态：开发中。阶段分支：`dev/large-photo-stability`。工程读取优化已经进入主线；此阶段在同一分支持续提交和验证，阶段末集中审核。

## 范围

1. 查明原尺寸细节窗口在擦除／添加切换后的偶发漏笔回归，保留原始失败，修复后覆盖真实触摸与工程往返。
2. 减少大照片初次导入的完整原图字节复制，保留原字节、尺寸、方向、色彩解释与失败保护。
3. 验证导入→调整→保存→重开→照片导出，以及外部工程往返和升级保留已有工程。

本阶段保持210MP／64MiB边界、v6工程语义和8位sRGB/SDR输出。原图全面文件化、分块原尺寸编码、完整HDR／RAW和其他平台另设阶段。日常手机试用与模拟器故障注入分开。

## 验收条件

- 对漏笔问题取得可复现的原因和对照证据；既有坐标、取消、撤销、比较、旋转与重开断言保留。
- 导入内存改进具有受限堆／预算验证，且真实编码照片经过应用路径往返，原图哈希不变；拒绝不破坏已有工程。
- JVM、构建、Lint和适用Android矩阵通过；基础设施失败与产品／测试失败分别留证，不以反复重跑代替修复。
- 提供对应干净提交的试用APK、已知边界及升级验证；清理被替代编译产物。
- 普通真机试用由使用者自行完成；没有结果时不宣称真机兼容性或人像画质已验收。
