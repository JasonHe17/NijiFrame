# 使用 NijiFrame

从[项目首页](../README.md)了解功能与试用入口。

## 从照片开始

导入一张照片，或打开此前导出的 `.nijiproj` 工程。编辑器会保留一份原图副本，调整通过参数记录。主页可重命名、复制或删除工程；副本可独立编辑。

## 调整、保存与导出

1. 导入照片或打开工程，选择工具查看实时预览。点“完成”应用当前工具；“取消”还原本次工具中的修改。先完成或取消当前工具，再选择其他工具；返回时若有改动，可选择应用、放弃或继续编辑。
2. 已应用的修改自动保存；请留意“调整待应用”“自动保存中”“已保存”状态。未应用的工具预览不属于自动保存内容，进程结束后不保证恢复。重置全部调整可撤销；跨工程重开不保留完整撤销历史。
3. 从“项目”回到主页管理多个作品。工程保存完整原图副本和参数，移动外部原图后仍可编辑。删除工程不删除外部原图；卸载应用会删除内部工程，请提前导出重要作品。
4. 打开“导出”设置不会应用草稿；确认保存照片／工程或分享时才应用并保存当前调整。关闭设置可继续编辑，取消系统位置选择不会撤回已经应用的修改。“导出”可选择照片格式、质量、原尺寸或缩小长边；不会放大小图。导出照片不复制 GPS 等原图元数据。导出工程包含原图及其原始元数据，适合备份和继续编辑。

当前输入范围为 常见广色域 JPEG、8/16 位不透明 PNG、静态 WebP 与系统可解码的 HEIC/HEIF、AVIF，上限 2.1 亿像素、64 MiB，单边不超过 32768 像素。透明像素、独立 HLG/PQ HDR 及其他不支持的输入会明确提示；普通广色域及 SDR 底图的 Ultra HDR JPEG 会转换到 sRGB／SDR 工作空间。此限制尚未经真机性能验证。工程格式仍为实验版本；可读取并迁移 v1–v6 工程，新保存使用 v7。


点击编辑器顶部的工程名称，或菜单中的“工程与照片信息”，可查看保存状态、草稿说明、源照片尺寸、格式与颜色转换信息。旧系统解码可能偏色的提醒仍会直接显示。

## 外观与参数控制

首页“外观”或编辑器更多菜单的“外观与查看”提供浅色、深色与跟随系统。画布背景可独立选择自动、浅灰、中灰或深灰；只影响查看，照片和工程参数不变。

工具分为调整、修饰、构图和预设。曝光等带正负方向的参数采用固定指针刻度：向左推动刻度增大数值，向右减小；点下不跳值，抬手即停。“精细”降低调整幅度。柔肤、锐化与笔刷属性保留全范围直轨。

点击数值可以直接输入，或用加减按钮微调；带正负方向的参数还提供“正负切换”，不依赖数字键盘是否提供负号。非法和越界值会提示，取消输入不修改照片。“复位”恢复当前参数默认值。参数带有文字、选中标记和改动小点；点“全部”可展开参数列表。所有工具都支持草稿内撤销／重做，完成后再按整个工具会话撤销。

## 局部曝光

1. 选择“修饰 → 编辑选区”，在“选区与修正”中用“添加区域”涂选。通过“笔刷大小”和“边缘硬度”设置之后笔画的覆盖范围；“擦除区域”移除覆盖。
2. 打开“显示区域”检查红色覆盖，关闭后查看真实效果。切换“调整效果”会隐藏覆盖并停止绘制。调整“局部曝光”只影响涂选区域；初始曝光为0，不会自动变亮。
3. 切换“移动画布”后可缩放／平移；整图绘制模式下双指也可导航，并取消当前未完成笔画；再切回添加或擦除继续绘制。笔画落在原图坐标中，裁剪、旋转后仍对应原有内容。
4. 画布下方撤销／重做在工具打开时操作当前草稿中的笔画与参数；“取消”放弃本次工具操作，“完成”保存整个工具事务。离开工具后撤销／重做操作已完成的工具调整；每个工具会话记为一步。

当前最多保留4个独立选区。用“新增选区”建立脸部、衣服或背景区域，在当前选区按钮的列表中切换；“管理选区”可命名、启用／关闭效果、复位本区效果或删除。每区最多128笔／4096个采样点，全工程最多256笔／8192点；超限会拒绝本次修改，原有区域保留。概览笔画沿用1024长边网格，原尺寸细节修正另按源像素计算；此版本不是逐根头发的智能抠图工具。可使用下文的人像几何区域建议，但没有智能吸附或精确皮肤分割；柔肤候选见下节。

大图调整时可能先显示“快速预览 · 正在精算”，随后替换为精确结果。细节和边缘在快速预览中可能不同，请等精算完成后判断；照片导出始终重新计算完整结果，不导出红色区域覆盖。

## 柔肤候选（实验）

先在“修饰 → 编辑选区 → 选区与修正”中涂选要调整的皮肤，避开眼睛、嘴唇、眉毛、胡须、发丝与眼镜；进入“调整效果”，选择“柔肤”并从较低强度开始。强度默认0，空区域不会改变照片。关闭“显示区域”，等待快速预览的精算标识消失后，再在100%附近检查皮肤细节。

“细节保护”越高，越少平滑局部颜色变化；它不认识五官或皮肤，不能代替手工擦除不应处理的区域。每个选区独立保存曝光、色温、色调、饱和度、柔肤和细节保护。同一区的这些效果共用覆盖范围；不同区按创建顺序合成，重叠处可能叠加强度。切换选区不会改变顺序，自动人像建议只替换当前选区。柔肤强度归零仅关闭本区柔肤，保留本区颜色和其他选区；取消整个工具会放弃本次全部草稿。

效果刻意偏温和，但高强度或低细节保护仍可能损失纹理。当前没有最终人像画质承诺，也没有自动美白、脸型修改或模型下载。工程会保存这些参数；新保存的v7工程不能用旧版本编辑器重新打开，升级前可先另存旧工程备份。

## 照片与工程有什么区别？

| 导出内容 | 适合用途 | 保存的信息 |
| --- | --- | --- |
| JPEG／PNG 照片 | 分享、展示、在其他应用中使用 | 当前编辑结果；不复制原图元数据 |
| `.nijiproj` 工程 | 备份、重新打开后继续调整 | 原始编码文件与编辑参数；包含原图原有的元数据 |

如果只是要分享图片，选择照片导出或系统分享。需要保留可编辑版本时，另存工程。Windows 端尚未提供，当前工程包可以在 NijiFrame Android 开发版中重新打开。

导出时会显示“处理照片”“编码照片”或“打包工程”，准备期间可以取消。准备完成后显示“正在写入文件”，此时取消按钮消失，请等待写入结果。编码／打包失败或准备期间取消不会提前打开目标文件；最终写入若因空间、权限或存储服务失败，目标仍可能不完整，请换个位置重新导出。应用内已保存的工程仍保留。导出需要额外临时空间，详见[导出行为](export-behavior.md)。

导出面板会提前检查当前尺寸与调整预计需要的内存。预计不足时，照片保存和分享暂不可用；可以采用面板建议的较小尺寸、重新检查内存，或切换到“可编辑工程”备份。面板的“查看原尺寸细节”不会应用草稿。检查通过不保证导出一定成功，最终开始时仍会再次检查；可用内存、临时存储和文件提供方状态都可能变化。

## 常见问题

**为什么关闭后有的调整没有保留？** 已应用的修改会自动保存，工具中的未应用预览不会。离开前查看“已保存”状态；返回主页时可选择应用或放弃草稿。

**为什么重开后不能撤销到之前的每一步？** 工程保留当前参数，不保留跨次打开的完整撤销历史。需要探索多个版本时，先在主页创建副本。

**为什么照片无法导入？** 请检查像素数、文件大小、色彩空间和透明度。RAW、TIFF、独立 HLG/PQ HDR 和透明PNG尚未支持；常见广色域和 Ultra HDR JPEG 可以按 sRGB／SDR 导入；应用会提示已识别的不支持输入。

**卸载前需要做什么？** 导出需要保留的 `.nijiproj` 工程。内部自动保存不等于外部备份；卸载应用会移除内部工程。

## 高像素照片

超过800万像素的照片会使用有明确标识的缩略预览，原图和源尺寸编辑坐标完整保留；放大预览不能等同于检查原图100%细节。原尺寸导出重新读取原图，导出前会检查预计内存；不足时提示选择长边4000、2048或1280，不自动改动所选尺寸。较小尺寸导出会从原始编码照片按所需分辨率读取，不使用屏幕预览图，细节效果可能与原尺寸导出后缩小略有差异。大幅裁剪后仍可能需要高分辨率源数据。更多边界见[大图处理](large-images.md)。

## 原尺寸细节查看（0.6）

在画布下方点“细节”，或从编辑菜单选择“原尺寸细节”。点击上方概览选择位置，白框表示正在检查的区域；下方一张图像像素对应一个屏幕像素，不会把缩略预览放大。“查看原图／查看调整”只比较颜色与细节效果，保留当前构图。关闭或系统返回即可继续编辑。

当前工具的未应用草稿也能查看；打开、对比和关闭细节都不会自动应用或保存它。裁剪工具正在操作时，查看的是画布上的完整构图，应用裁剪后再查看裁剪结果。细节窗口一次最多768×768像素，支持已接受的照片编码、拍摄方向、局部效果、旋转翻转、裁剪、锐化与暗角。几何重采样可能有细微舍入差异，最终文件仍以导出为准。此功能没有改变原尺寸导出的内存限制，也不代表已完成人像画质验收。

## 人像区域建议

在“修饰 → 编辑选区”中点击“建议人像区域（实验）”，检查覆盖区域后选择“采用并修正”。它替换当前区域及笔画，可以撤销；原有曝光／柔肤强度保留，不会自动开启柔肤。可继续擦除眼镜、胡须、头发和遮挡，或补画遗漏位置；“保留原区域”不修改草稿。应用调整后才保存。

建议是粗略面部几何区域，不是精确皮肤识别。未找到清晰人脸、检测到多人或内存不足时继续使用手工区域。分析在本机执行；取消结果可能需要等待当前推理完成。详见[范围与限制](portrait-regions.md)。新工程为 v7，旧版应用无法打开，升级前请备份重要工程。“关于”可查看应用版本、构建编号和源码提交，反馈问题时附上这些信息。

整图未检出时会自动尝试有限分区，可能比原来多等待片刻；不同分区找到多个面部候选时，继续使用手工区域。分区不会裁切你的照片，也不会自动提高柔肤强度；建议仍需检查后采用。

在“局部”工具内打开细节窗口，还可以使用同样的“添加区域／擦除区域”，调节笔刷大小、边缘硬度、覆盖显示，撤销或重做笔画。硬度共用；概览显示相对笔刷直径，原尺寸细节使用独立的1–128原图像素直径；“仅查看”停止绘制。上方概览用于换位置，下方按原尺寸涂抹；横屏或较矮的窗口可滚动上方控制区找到笔刷设置；小图周围的空白不接受笔画，滑出细节图像或双指触摸会取消当前笔画。对比原图时不能涂抹。关闭后仍是草稿，点“完成”才保存，点“取消”会放弃本次局部编辑，包括细节窗口里的修改。新增精细修正不会重解释已有笔画；微小笔画可能在概览中不可见，请在原尺寸细节检查。该能力不等于精确语义分割或点状修复。

## 广色域和手机照片兼容（dev.10）

支持常见 Display P3／Adobe RGB JPEG、带 SDR 底图的 Ultra HDR JPEG、8/16 位不透明 PNG、静态 WebP，以及系统可解码的 HEIC/HEIF（Android 9+）和 AVIF（Android 12+）。不再因普通广色域照片不是 sRGB 而直接拒绝，而是转换到当前 sRGB／SDR 编辑空间；原图和 HDR 增益图仍完整保存在工程内。导出的照片为 8 位 sRGB／SDR，不保留 HDR 高亮或全部广色域。相机可优先导出 JPEG／PNG，RAW、TIFF 仍未支持。HEIF／AVIF 的格式变体与内存要求取决于设备。

新保存的工程为 v7，能读取 v1–v6；旧版不能打开 v7，请先另存需要保留的旧工程。独立 HLG/PQ HDR、HDR 底图增益图、透明像素和动画会明确拒绝，不能把手机相册的显示效果等同于本应用的 SDR 导出效果。详细边界见[照片格式与色彩](photo-input.md)。

局部颜色可从“修饰 → 局部颜色”进入，在“调整效果 → 全部”中选择局部色温、色调或饱和度。色温为相对冷暖，不是Kelvin；所有局部参数仅修改当前选区。取消整个工具放弃本次各选区草稿，完成后统一保存；撤销按本次操作顺序回退。
