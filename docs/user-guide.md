# 使用 NijiFrame

从[项目首页](../README.md)了解功能与试用入口。

## 从照片开始

导入一张照片，或打开此前导出的 `.nijiproj` 工程。编辑器会保留一份原图副本，调整通过参数记录。主页可重命名、复制或删除工程；副本可独立编辑。

## 调整、保存与导出

1. 导入照片或打开工程，选择工具查看实时预览。点“应用调整”或切换工具会应用当前工具；“取消调整”还原本次工具中的修改。
2. 已应用的修改自动保存；请留意“调整待应用”“自动保存中”“已保存”状态。未应用的工具预览不属于自动保存内容，进程结束后不保证恢复。重置全部调整可撤销；跨工程重开不保留完整撤销历史。
3. 从“项目”回到主页管理多个作品。工程保存完整原图副本和参数，移动外部原图后仍可编辑。删除工程不删除外部原图；卸载应用会删除内部工程，请提前导出重要作品。
4. “导出”可选择照片格式、质量、原尺寸或缩小长边；不会放大小图。导出照片不复制 GPS 等原图元数据。导出工程包含原图及其原始元数据，适合备份和继续编辑。

当前输入范围为 sRGB JPEG 和 8 位不透明 PNG，上限 1 亿像素、64 MiB，单边不超过 32768 像素。透明、宽色域、已识别的 HDR 增益图及其他不支持的输入会明确提示。此限制尚未经真机性能验证。工程格式仍为实验版本；可读取并迁移 v1／v2／v3／v4 工程，新保存使用 v5。


## 局部曝光

1. 选择“局部”，用“添加区域”涂选。通过“笔刷大小”和“边缘硬度”设置之后笔画的覆盖范围；“擦除区域”移除覆盖。
2. 打开“显示区域”检查红色覆盖，关闭后查看真实效果。调整“局部曝光”只影响涂选区域；初始曝光为0，不会自动变亮。
3. 切换“移动画布”后可双指缩放／平移；再切回添加或擦除继续绘制。笔画落在原图坐标中，裁剪、旋转后仍对应原有内容。
4. 顶部撤销／重做在局部工具打开时操作当前草稿中的笔画与曝光；“取消调整”放弃本次工具操作，“应用调整”保存整个工具事务。离开工具后顶部撤销／重做操作已应用的调整。

当前支持一个区域、最多128笔／4096个采样点，覆盖网格长边最多1024。复杂度超限会提示，可撤销或清空区域；此版本不用于逐根头发等精细抠图。可使用下文的人像几何区域建议，但没有智能吸附或精确皮肤分割；柔肤候选见下节。

大图调整时可能先显示“快速预览 · 正在精算”，随后替换为精确结果。细节和边缘在快速预览中可能不同，请等精算完成后判断；照片导出始终重新计算完整结果，不导出红色区域覆盖。

## 柔肤候选（实验）

先在“局部”中涂选要调整的皮肤，避开眼睛、嘴唇、眉毛、胡须、发丝与眼镜；选择“柔肤（实验）”并从较低强度开始。强度默认0，空区域不会改变照片。关闭“显示区域”，等待快速预览的精算标识消失后，再在100%附近检查皮肤细节。

“细节保护”越高，越少平滑局部颜色变化；它不认识五官或皮肤，不能代替手工擦除不应处理的区域。曝光与柔肤共用当前一个区域。柔肤强度归零仅关闭柔肤，保留局部曝光；取消整个工具会放弃本次全部草稿。

效果刻意偏温和，但高强度或低细节保护仍可能损失纹理。当前没有最终人像画质承诺，也没有自动美白、脸型修改或模型下载。工程会保存这些参数；新保存的v5工程不能用旧版本编辑器重新打开，升级前可先另存旧工程备份。

## 照片与工程有什么区别？

| 导出内容 | 适合用途 | 保存的信息 |
| --- | --- | --- |
| JPEG／PNG 照片 | 分享、展示、在其他应用中使用 | 当前编辑结果；不复制原图元数据 |
| `.nijiproj` 工程 | 备份、重新打开后继续调整 | 原始编码文件与编辑参数；包含原图原有的元数据 |

如果只是要分享图片，选择照片导出或系统分享。需要保留可编辑版本时，另存工程。Windows 端尚未提供，当前工程包可以在 NijiFrame Android 开发版中重新打开。

## 常见问题

**为什么关闭后有的调整没有保留？** 已应用的修改会自动保存，工具中的未应用预览不会。离开前查看“已保存”状态；返回主页时可选择应用或放弃草稿。

**为什么重开后不能撤销到之前的每一步？** 工程保留当前参数，不保留跨次打开的完整撤销历史。需要探索多个版本时，先在主页创建副本。

**为什么照片无法导入？** 请检查像素数、文件大小、色彩空间和透明度。RAW、HDR、透明PNG与宽色域工作流尚未支持；应用会提示已识别的不支持输入。

**卸载前需要做什么？** 导出需要保留的 `.nijiproj` 工程。内部自动保存不等于外部备份；卸载应用会移除内部工程。

## 高像素照片

超过800万像素的照片会使用有明确标识的缩略预览，原图和源尺寸编辑坐标完整保留；放大预览不能等同于检查原图100%细节。原尺寸导出重新读取原图，导出前会检查预计内存；不足时提示选择长边4000、2048或1280，不自动改动所选尺寸。较小尺寸导出会从原始编码照片按所需分辨率读取，不使用屏幕预览图，细节效果可能与原尺寸导出后缩小略有差异。大幅裁剪后仍可能需要高分辨率源数据。更多边界见[大图处理](large-images.md)。

## 原尺寸细节查看（0.6）

在画布右下角点“查看细节”，或从编辑菜单选择“原尺寸细节”。点击上方概览选择位置，白框表示正在检查的区域；下方一张图像像素对应一个屏幕像素，不会把缩略预览放大。“查看原图／查看调整”只比较颜色与细节效果，保留当前构图。关闭或系统返回即可继续编辑。

当前工具的未应用草稿也能查看；打开、对比和关闭细节都不会自动应用或保存它。裁剪工具正在操作时，查看的是画布上的完整构图，应用裁剪后再查看裁剪结果。细节窗口一次最多768×768像素，支持JPEG／PNG、拍摄方向、局部效果、旋转翻转、裁剪、锐化与暗角。几何重采样可能有细微舍入差异，最终文件仍以导出为准。此功能没有改变原尺寸导出的内存限制，也不代表已完成人像画质验收。

## 人像区域建议

在“局部”中点击“建议人像区域（实验）”，检查覆盖区域后选择“采用并修正”。它替换当前区域及笔画，可以撤销；原有曝光／柔肤强度保留，不会自动开启柔肤。可继续擦除眼镜、胡须、头发和遮挡，或补画遗漏位置；“保留原区域”不修改草稿。应用调整后才保存。

建议是粗略面部几何区域，不是精确皮肤识别。未找到清晰人脸、检测到多人或内存不足时继续使用手工区域。分析在本机执行；取消结果可能需要等待当前推理完成。详见[范围与限制](portrait-regions.md)。新工程为 v5，旧版应用无法打开，升级前请备份重要工程。“关于”可查看应用版本、构建编号和源码提交，反馈问题时附上这些信息。
