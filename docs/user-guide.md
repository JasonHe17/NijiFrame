# 使用 NijiFrame

从[项目首页](../README.md)了解功能与试用入口。

## 从照片开始

导入一张照片，或打开此前导出的 `.nijiproj` 工程。编辑器会保留一份原图副本，调整通过参数记录。主页可重命名、复制或删除工程；副本可独立编辑。

## 调整、保存与导出

1. 导入照片或打开工程，选择工具查看实时预览。点“应用调整”或切换工具会应用当前工具；“取消调整”还原本次工具中的修改。
2. 已应用的修改自动保存；请留意“调整待应用”“自动保存中”“已保存”状态。未应用的工具预览不属于自动保存内容，进程结束后不保证恢复。重置全部调整可撤销；跨工程重开不保留完整撤销历史。
3. 从“项目”回到主页管理多个作品。工程保存完整原图副本和参数，移动外部原图后仍可编辑。删除工程不删除外部原图；卸载应用会删除内部工程，请提前导出重要作品。
4. “导出”可选择照片格式、质量、原尺寸或缩小长边；不会放大小图。导出照片不复制 GPS 等原图元数据。导出工程包含原图及其原始元数据，适合备份和继续编辑。

当前输入范围为 sRGB JPEG 和 8 位不透明 PNG，上限 800 万像素、32 MiB。透明、宽色域、已识别的 HDR 增益图及其他不支持的输入会明确提示。此限制尚未经真机性能验证。工程格式仍为实验版本；可读取并迁移 v1／v2 工程，新保存使用 v3。


## 局部曝光

1. 选择“局部”，用“添加区域”涂选。通过“笔刷大小”和“边缘硬度”设置之后笔画的覆盖范围；“擦除区域”移除覆盖。
2. 打开“显示区域”检查红色覆盖，关闭后查看真实效果。调整“局部曝光”只影响涂选区域；初始曝光为0，不会自动变亮。
3. 切换“移动画布”后可双指缩放／平移；再切回添加或擦除继续绘制。笔画落在原图坐标中，裁剪、旋转后仍对应原有内容。
4. 顶部撤销／重做在局部工具打开时操作当前草稿中的笔画与曝光；“取消调整”放弃本次工具操作，“应用调整”保存整个工具事务。离开工具后顶部撤销／重做操作已应用的调整。

当前支持一个区域、最多128笔／4096个采样点，覆盖网格长边最多1024。复杂度超限会提示，可撤销或清空区域；此版本不用于逐根头发等精细抠图。尚无智能吸附、自动皮肤区域或磨皮。

大图调整时可能先显示“快速预览 · 正在精算”，随后替换为精确结果。细节和边缘在快速预览中可能不同，请等精算完成后判断；照片导出始终重新计算完整结果，不导出红色区域覆盖。

## 照片与工程有什么区别？

| 导出内容 | 适合用途 | 保存的信息 |
| --- | --- | --- |
| JPEG／PNG 照片 | 分享、展示、在其他应用中使用 | 当前编辑结果；不复制原图元数据 |
| `.nijiproj` 工程 | 备份、重新打开后继续调整 | 原始编码文件与编辑参数；包含原图原有的元数据 |

如果只是要分享图片，选择照片导出或系统分享。需要保留可编辑版本时，另存工程。Windows 端尚未提供，当前工程包可以在 NijiFrame Android 开发版中重新打开。

## 常见问题

**为什么关闭后有的调整没有保留？** 已应用的修改会自动保存，工具中的未应用预览不会。离开前查看“已保存”状态；返回主页时可选择应用或放弃草稿。

**为什么重开后不能撤销到之前的每一步？** 工程保留当前参数，不保留跨次打开的完整撤销历史。需要探索多个版本时，先在主页创建副本。

**为什么照片无法导入？** 请检查像素数、文件大小、色彩空间和透明度。RAW、HDR、透明PNG与宽色域工作流尚未支持；应用会提示已识别的不支持输入。

**卸载前需要做什么？** 导出需要保留的 `.nijiproj` 工程。内部自动保存不等于外部备份；卸载应用会移除内部工程。
